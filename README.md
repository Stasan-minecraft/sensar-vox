# SENSAR VOX

Безкоштовна голосова диктовка для будь-якого додатку — повністю локально, без API-ключів.
Free voice dictation for any app — fully local, no API keys.

## ⬇️ Завантажити / Download

**[Остання версія / Latest release →](https://github.com/Stasan-minecraft/sensar-vox/releases/latest)**

| Система | Файл |
|---|---|
| Mac з M1–M4 (Apple Silicon) | `SENSAR-VOX-…-mac-AppleSilicon.dmg` |
| Mac з Intel | `SENSAR-VOX-…-mac-Intel.dmg` |
| Windows 10/11 | `SENSAR-VOX-…-Windows-Setup.exe` |

Після встановлення VOX оновлюється сам: коли виходить нова версія, достатньо натиснути «Оновити».
After installing, VOX updates itself — just click “Update” when a new version is out.

### Перший запуск на Mac / First launch on Mac
Перетягніть програму в «Програми» і виконайте в Терміналі / Drag to Applications and run in Terminal:
```
xattr -cr "/Applications/SENSAR VOX.app"
```
Далі дозвольте «Мікрофон» і «Універсальний доступ». / Then allow Microphone and Accessibility.

### Windows
Якщо SmartScreen попередить — «Докладніше» → «Виконати в будь-якому разі». / If SmartScreen warns — “More info” → “Run anyway”.
